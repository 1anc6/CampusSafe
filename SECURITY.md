# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security or privacy problem.
Send a concise report to the project maintainers with steps to reproduce, the
affected route or component, and any suggested mitigation. Do not include real
student records, credentials, phone numbers, or location data.

We will acknowledge reports, assess impact, and coordinate a fix before public
disclosure. Safety and privacy defects affecting SOS, reports, authentication,
or location sharing are treated as urgent.

## Supported version

Security fixes are made on the current `main` branch and released with the
next deployment.
