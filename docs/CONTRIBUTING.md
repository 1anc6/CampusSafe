# Contributing to CampusSafe

Thank you for helping improve a safer, more accessible campus experience.

## Before you open a pull request

- Keep each change focused and explain the student or responder outcome it improves.
- Never add real phone numbers, student data, GPS traces, API keys, or credentials.
- Run `npm run typecheck`, `npm run lint`, and `npm test` when the relevant tooling is available.

## Safety-first changes

Do not represent the product as an emergency service. Preserve clear escalation guidance, respect privacy defaults, and make critical actions usable by keyboard and screen reader.
