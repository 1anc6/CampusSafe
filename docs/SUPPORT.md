# Support guide

CampusSafe is a coordination tool. It does not replace local emergency services.

## When someone needs immediate help

Use the appropriate local emergency channel first. A report in the app may be
used to provide context, but users should not wait for an in-app response when
there is immediate danger.

## Common support checks

- Confirm the user is on the right role-specific area after signing in.
- Check whether location access is blocked by browser permission or a non-HTTPS
  address before assuming GPS is broken.
- Do not ask a user to post screenshots containing personal details or a report
  tracking code in public channels.

For potential account, privacy, or access-control defects, use `SECURITY.md`.
